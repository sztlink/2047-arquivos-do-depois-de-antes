## How this enters 2047

### 1. Continuous printing is a formal problem

Do not treat the dot-matrix printer as mere output. The form of the work passes through:

- real width;
- paper feed;
- spooling;
- fragmentation of image and text;
- noise;
- accent and character failure;
- printing time;
- physical accumulation.

### 2. A reactivated technical chain

The SUN-2 / 68000 item suggests a good model for 2047:

```txt
old file or documentation -> contemporary host -> adapter or intermediary -> machine and physical output
```

This pattern is more interesting than emulating everything. It keeps the friction.

### 3. Identical material is not necessarily the same

The TI 5532 case matters as a warning: components and platforms can keep name and part number while changing inside. For 2047, this reinforces the need to record:

- exact model;
- batch when available;
- driver;
- print mode;
- paper;
- encoding;
- photos and scans;
- payload hash.
